Back up and restore records

Download a JSON backup for safekeeping. To transfer records to another device, download the backup here and import it on that device.

Importing a backup replaces the current records in this browser. Keep a copy of your existing data first.

Cross-device sync

This version syncs student, attendance, and score records to the signed-in administrator’s Firebase account. Keep regular backups as an extra precaution.

Cloud sync statusCloud sync requires Firebase Authentication and the matching Firestore rules to be configured. Only the signed-in administrator can access this account’s records.

For now, use the backup/import feature to move data manually. Do not store sensitive student or parent information on a shared device.

Sign out when finished, especially on a shared device.
